## BR-01: Несоответствие изображения товара для пользователя problem_user

- **Серьёзность:** S3 (Minor)
- **Приоритет:** P3 (Low)
- **Окружение:** Браузер Chrome 120, Windows 10
- **Компонент:** Страница каталога товаров (/inventory.html)

**Шаги воспроизведения:**
1. Авторизоваться как `problem_user` с паролем `secret_sauce`.
2. Перейти на главную страницу с каталогом товаров.
3. Обратить внимание на карточку товара "Sauce Labs Backpack".

**Фактический результат:**  
На карточке товара "Sauce Labs Backpack" отображается изображение, не соответствующее товару (например, изображение от другого товара).

**Ожидаемый результат:**  
На карточке товара отображается его собственное корректное изображение.

## BR-02: Сортировка товаров по цене не работает для problem_user

- **Серьёзность:** S3 (Minor)
- **Приоритет:** P2 (Medium)
- **Окружение:** Браузер Chrome 120, Windows 10
- **Компонент:** Страница каталога товаров (/inventory.html)

**Шаги воспроизведения:**
1. Авторизоваться как `problem_user` с паролем `secret_sauce`.
2. На главной странице каталога найти выпадающий список сортировки (в правом верхнем углу).
3. Выбрать вариант **«Price (low to high)»**.
4. Обратить внимание на порядок отображения товаров.

**Фактический результат:**  
Порядок товаров не меняется относительно начального (или меняется хаотично, но не по возрастанию цены). Например, самый дешёвый товар может оказаться не первым.

**Ожидаемый результат:**  
Товары должны отображаться в порядке возрастания цены (от самой низкой к самой высокой).
