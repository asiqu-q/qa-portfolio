# Баг-репорты по SauceDemo

## BR-01: Несоответствие изображения товара для пользователя problem_user

- **Серьёзность:** S3 (Minor)
- **Приоритет:** P3 (Low)
- **Окружение:** Браузер Chrome 120, Windows 10
- **Компонент:** Страница каталога товаров (/inventory.html)

**Шаги воспроизведения:**
1. Авторизоваться как `problem_user` с паролем `secret_sauce`.
2. Перейти на главную страницу с каталогом товаров.
3. Обратить внимание на карточку товара "Sauce Labs Backpack".

**Фактический результат:**  
На карточке товара "Sauce Labs Backpack" отображается изображение, не соответствующее товару.

**Ожидаемый результат:**  
На карточке товара отображается его собственное корректное изображение.
