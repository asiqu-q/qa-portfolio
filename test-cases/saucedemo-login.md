# Тест-кейсы для тестирования авторизации на SauceDemo

## Предусловия
- Сайт открыт по адресу https://www.saucedemo.com/
- Браузер: Google Chrome (последняя версия)

| TC ID | Название | Предусловие | Шаги | Ожидаемый результат |
|-------|----------|-------------|------|----------------------|
| TC-01 | Успешный вход | Сайт открыт | 1. Ввести логин `standard_user`<br>2. Ввести пароль `secret_sauce`<br>3. Нажать кнопку Login | Пользователь перенаправляется на страницу `/inventory.html`. Отображается каталог товаров. |
| TC-02 | Вход с неверным паролем | Сайт открыт | 1. Ввести логин `standard_user`<br>2. Ввести пароль `wrong_password`<br>3. Нажать кнопку Login | Появляется сообщение об ошибке: *"Username and password do not match any user in this service"* |
| TC-03 | Вход с пустыми полями | Сайт открыт | 1. Оставить поля логина и пароля пустыми<br>2. Нажать кнопку Login | Появляется сообщение об ошибке: *"Username is required"* |
| TC-04 | Вход с пустым паролем | Сайт открыт | 1. Ввести логин `standard_user`<br>2. Оставить поле пароля пустым<br>3. Нажать кнопку Login | Появляется сообщение об ошибке: *"Password is required"* |
| TC-05 | Вход заблокированного пользователя | Сайт открыт | 1. Ввести логин `locked_out_user`<br>2. Ввести пароль `secret_sauce`<br>3. Нажать кнопку Login | Появляется сообщение об ошибке: *"Sorry, this user has been locked out"* |
| TC-06 | Добавление товара в корзину | Пользователь авторизован (`standard_user`), открыт каталог товаров | 1. Нажать кнопку "Add to cart" у товара "Sauce Labs Backpack"<br>2. Обратить внимание на иконку корзины в правом верхнем углу | Иконка корзины отображает число "1". |
| TC-07 | Удаление товара из корзины | В корзине есть 1 товар | 1. Перейти в корзину (нажать на иконку)<br>2. Нажать кнопку "Remove" у товара<br>3. Проверить содержимое корзины | Товар исчезает из списка, корзина пуста. |
| TC-08 | Оформление заказа с валидными данными | В корзине есть товар | 1. Нажать кнопку "Checkout"<br>2. Заполнить поля: First Name = "John", Last Name = "Doe", Zip/Postal Code = "12345"<br>3. Нажать "Continue"<br>4. Нажать "Finish" | Появляется сообщение: *"Thank you for your order!"* |
